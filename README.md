# StudySync

> **Неофициальное приложение.** StudySync — личный студенческий проект, он не связан с КГЭУ
> и не является его официальным продуктом. Расписание загружается из публичного расписания
> КГЭУ по номеру группы, без входа в личный кабинет и без логинов и паролей. Все данные
> (расписание, задачи, конспекты) хранятся только на устройстве пользователя.

**StudySync** — офлайн-мобильное приложение для студентов и школьников: учебный планировщик,
расписание занятий, менеджер заданий с дедлайнами, таймер концентрации (Pomodoro), аналитика
продуктивности и **умный перепланировщик**, который помогает перераспределять задачи при перегрузе.

Приложение не отправляет данные на сервер, не использует агрессивные уведомления и манипулятивные
механики. Все данные хранятся локально в SQLite.

## Быстрый старт

Требуется Node.js ≥ 20 и npm ≥ 10.

```bash
npm install          # зависимости (уже зафиксированы в package-lock.json)
npm start            # Metro dev-сервер (Expo Go: отсканируйте QR или нажмите a / i)
```

### Запуск на эмуляторе / устройстве

```bash
npm run android      # Android-эмулятор или устройство с Expo Go по USB/Wi-Fi
npm run ios          # iOS-симулятор (macOS) или устройство с Expo Go
npm run web          # веб-версия (ограниченно: уведомления и sharing недоступны в браузере)
```

- **Android**: установите Expo Go (или соберите dev-клиент), выполните `npm run android`.
- **iOS**: Expo Go из App Store, затем `npm run ios`.
- Для уведомлений на Android 13+ приложение запросит разрешение при первом включении напоминаний;
  отказ обрабатывается корректно (см. `src/notifications/client.ts`).

### Демо-версия

```bash
npm run start:demo                                  # демо в Expo Go
eas build --platform android --profile demo        # APK демо-версии
```

Демо ставится рядом с обычной версией и предлагает заполнить приложение примером данных. Подробнее — `docs/DEMO.md`.

### Продакшен-сборки (EAS)

```bash
npm install -g eas-cli && eas login
eas build --platform android --profile preview     # APK для установки на устройство
eas build --platform android --profile production  # AAB для Google Play
eas build --platform ios --profile production      # IPA / TestFlight
```

Профили объявлены в `eas.json`. Локальная проверка бандла без устройства:

```bash
npx expo export --platform android   # Hermes-бандл в dist/ (проверено в CI-режиме)
npx expo export --platform ios
```

### Тесты и проверка типов

```bash
npm test              # весь набор (193 теста: логика + навигация)
npm run test:logic    # только логика и БД (реальный SQLite через SQL.js)
npm run test:app      # навигация и экраны (renderRouter)
npm run typecheck     # tsc --noEmit в strict-режиме
```

## Новое

- **Расписание КГЭУ**: импорт по группе; в карточке пары — аудитория, преподаватель, вид занятия, замены.
- **Утренняя сводка** (вкл/выкл, время): пары, дедлайны, этапы и отработки на день.
- **Шаблоны работ**: курсовая, лабораторная, реферат, экзамен, практика — этапы-подзадачи со сроками
  от даты защиты, с пропорциональным сжатием при нехватке времени.
- **Долги и отработки**: попытки и пересдачи, дата и аудитория, преподаватель из расписания,
  чек-лист «что взять», напоминание за час.
- **Конспекты к парам**: фото доски (со сжатием) и заметки, привязка к паре, подборка «Важное»;
  фото по желанию попадают в резервную копию.
- **Поиск расписания**: по группе, преподавателю и аудитории (публичное API личного кабинета),
  по предмету — в своём расписании и фильтром внутри любого открытого расписания; недавние запросы.
- **Автообновление своей группы** при открытии приложения (вкл/выкл, не чаще раза в 6 часов,
  пустой ответ сервера расписание не стирает).
- **Персонализация**: цвет акцента (6 вариантов), размер текста, стартовая вкладка,
  отключаемые блоки главной, компактные карточки пар.
- **Демо-режим** с примером данных.

## Реализованные возможности (v1)

- **Главная**: приветствие и дата, статистика дня, ближайшие занятия, задачи на сегодня,
  высокий приоритет, ближайшие дедлайны, индикатор загруженности дня (с предложением
  перепланировать при перегрузе), карточка активного таймера, быстрое добавление.
- **Расписание**: представления день/неделя/месяц; создание, редактирование, удаление событий;
  повторения (ежедневно/еженедельно, «до даты», редактирование серии или одного события);
  свободные промежутки; обнаружение конфликтов с понятным предупреждением (автоматических
  изменений нет); переход к дате.
- **Задачи**: CRUD, статусы (запланирована / в процессе / выполнена / отложена), приоритет,
  сложность, дедлайн, плановая и фактическая длительность, подзадачи, поиск, фильтры
  (статус/предмет/срок), сортировка, просроченные, перенос срока со счётчиком переносов,
  подтверждение удаления, запуск фокуса из карточки.
- **Фокус**: Pomodoro и секундомер, старт/пауза/продолжить/завершить/пропустить перерыв,
  настройка интервалов, кольцо прогресса, итоги; состояние восстанавливается после сворачивания
  и закрытия приложения по сохранённым меткам времени; паузы не считаются работой;
  сессии короче минуты не сохраняются (нет фиктивных данных).
- **Перепланировщик**: детерминированный локальный алгоритм; показывает предложенный порядок,
  время, причины, неразмещённые задачи с вариантами переноса; предупреждает о перегрузе;
  «Применить план» / «Изменить вручную» / «Отменить»; применение обратимо.
- **Прогресс**: выполненные задачи, процент выполнения, время фокуса, распределение по предметам,
  динамика 7/30 дней, просрочки, частота переносов, план/факт; фильтры периодов; честные
  «недостаточно данных» вместо выдуманных значений; цели (неделя/месяц/семестр).
- **Профиль**: имя, светлая/тёмная/системная тема (сохраняется), предметы (CRUD, архив,
  безопасное удаление), цели, настройки уведомлений и сессий, учебное окно, начало недели,
  экспорт/импорт JSON, внутренние резервные копии, полный сброс с двойным подтверждением.
- **Импорт расписания КГЭУ** (Профиль → «Расписание КГЭУ»): поиск группы по публичному API
  личного кабинета (пароль не нужен), предпросмотр периода/занятий/замен, идемпотентная
  синхронизация (добавление новых, обновление изменённых, удаление отменённых занятий)
  без затрагивания созданных вручную событий; происхождение событий помечается бейджем.
  Дисциплины расписания автоматически становятся предметами: существующие предметы с теми
  же названиями переиспользуются, дубликаты не создаются, при удалении импорта предметы
  сохраняются.
- **Расписание, режим месяца**: тап по дню показывает расписание выбранного дня под сеткой
  месяца (режим не переключается); кнопка «Дневной вид» открывает день отдельным экраном.
- **Уведомления**: начало занятия, приближение дедлайна, конец рабочей фазы и перерыва;
  раздельные настройки; корректная обработка отказа ОС; отсутствие дубликатов после правок
  (детерминированные идентификаторы).

## Известные ограничения v1

- Продакшен-сборка на реальном устройстве/эмуляторе в этой среде не выполнялась
  (нет Android SDK/Xcode); проверены: бандл Metro (Hermes, android+ios), dev-сервер,
  107 автоматизированных тестов, включая рендер всех экранов (на 10.10.2026 набор
  вырос до 193 тестов — см. `docs/TEST-RESULTS.md`).
- Веб-версия работоспособна частично: локальные уведомления и системный шаринг файла
  недоступны в браузере (приложение честно сообщает об этом).
- Импорт внешних календарей (Google/Apple Calendar) не реализован — заложена основа
  (модель событий, серия, свободные слоты) для будущей версии.
- Совместные группы, аккаунты и облачная синхронизация — будущие версии (архитектура
  допускает добавление без переработки слоёв).
