# Демо-версия StudySync

Демо — та же программа, собранная с переменной `APP_VARIANT=demo` (см. `app.config.js`):

- название «StudySync Demo», пакет `app.studysync.demo` — ставится **рядом** с обычной версией;
- на экране приветствия кнопка «Посмотреть на примере» заполняет приложение примером данных
  (расписание на 3 недели, задачи, курсовая по шаблону, долги, конспект, статистика);
- в профиле карточка «Демо-версия» с контактом для отзывов.

## Проверить демо в Expo Go

```
npm run start:demo
```

## Собрать APK для других (Android)

Нужен бесплатный аккаунт на https://expo.dev.

```
npm install -g eas-cli
eas login
eas init                       # один раз: привязать проект к аккаунту
eas build --profile demo --platform android
```

Сборка идёт на серверах Expo 10–20 минут. В конце EAS покажет ссылку и QR-код на страницу сборки:
по ней можно скачать `.apk` и разослать файл или саму ссылку.

Контакт для отзывов необязателен. Чтобы он показывался в профиле демо-версии, добавьте в `eas.json` → `build.demo.env` строку `"FEEDBACK_CONTACT": "@ваш_ник"` (пустое значение EAS не принимает — если контакт не нужен, строки быть не должно).

## Как установить получателю

1. Скачать `.apk` на телефон.
2. Открыть файл; Android попросит разрешить установку из этого источника (браузера/Telegram) — разрешить.
3. Если Google Play Protect предупредит о неизвестном разработчике — «Всё равно установить».

Новая версия = новая сборка `eas build --profile demo`; установка поверх сохраняет данные.
